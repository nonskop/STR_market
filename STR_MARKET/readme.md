# README: Инструкция к проекту Airsoft-Rus

Данный файл содержит техническое описание архитектуры, настройки окружения и работы с базой данных для учебного проекта магазина страйкбольного оборудования.

---

## 1. Технологический стек
* **Frontend:** HTML5, CSS3, JavaScript (ES6+).
* **Backend:** Node.js (платформа), Express.js (фреймворк).
* **Database:** SQLite3 (встраиваемая реляционная БД).

---

## 2. Архитектура и база данных

### Подключение БД
База данных хранится в локальном файле `str_market.db`. Подключение реализовано в `APP.js` через библиотеку `sqlite3`. Сервер создает прямое соединение с файлом, что исключает необходимость настройки внешних серверов БД.

### Структура данных
* **Таблица `users`**: Хранит учетные записи. Поля: `id`, `username`, `password`, `role`.
* **Таблица `products`**: Хранит каталог товаров. Поля: `id`, `title`, `price`, `description`, `category`.

### Взаимодействие (Data Flow)
1.  **Запрос**: Браузер отправляет асинхронный запрос (`fetch`) на эндпоинт сервера (например, `POST /api/products`).
2.  **Обработка**: `APP.js` принимает данные, формирует SQL-запрос и выполняет его в `str_market.db`.
3.  **Ответ**: Сервер возвращает JSON-объект с результатом операции, который фронтенд отображает пользователю.

---

## 3. Инструкция по запуску

### Шаг 1: Установка зависимостей
Требуется установленный Node.js. Выполните команду в корневой папке проекта:
```bash
npm install express sqlite3 cors
Шаг 2: Запуск сервера
Запустите серверную часть:

Bash
node APP.js
Сервер по умолчанию работает на порту 3000.

Шаг 3: Клиентская часть
Откройте index.html через любой локальный сервер (например, Live Server в VS Code).

4. Панель администратора
Панель управления товарами (#admin-panel) активируется в script.js функцией checkAdminAccess().

Логика отображения: Проверяет наличие ключа user в localStorage.

Права доступа: На текущем этапе панель отображается для любого авторизованного пользователя. Для ограничения доступа необходимо изменить условие в script.js, добавив проверку поля role.

5. Важные замечания
CORS: В APP.js подключен модуль cors для разрешения запросов между разными портами (фронтенд и бэкенд).

Стейт: Авторизация сохраняется через localStorage.setItem('user', ...), что позволяет сохранять сессию при перезагрузке страницы.
